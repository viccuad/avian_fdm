# Migrating From v0.3 to `main`

This file contains migration guides for breaking changes that have happened on the `main` branch
since the latest release. These guides are evolving and may not be polished yet.

See [migration-guides/README.md](./README.md) and existing entries for information about AvianFDM's
migration guide process and what to put here.

## `AtmosphereState` uses geopotential altitude

`AtmosphereState` incorreclty used the geometric altitude directly in the ISA formulas, as it
was partially implemented.
ICAO defines the ISA in geopotential altitude `H = r0 * h / (r0 + h)`, with `r0` = 6 356 766 m.
The atmosphere system now converts the geometric altitude `h` to `H` first.
Note that `FlightState::altitude_m` is still the geometric altitude, as this is just for
geometry.

At the same geometric altitude, the air is now slightly denser: about +0.002% at 1 km, +0.015% at
3 km, +0.2% at 10 km, and +1% at 20 km. The tropopause moves from `h` = 11 000 m to 11 019 m.

No code change is necessary. If a test compares `AtmosphereState` with ISA table values, convert
the table altitude to a geometric altitude: `h = r0 * H / (r0 - H)`.
